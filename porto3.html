Desain antarmuka portfolio dengan Box Model & Flexbox.

Tentang Proyek

Proyek ini mengeksplorasi cara menyusun halaman portfolio dengan struktur yang rapi menggunakan CSS Box Model dan Flexbox. Hasilnya adalah halaman yang teratur, seimbang, dan nyaman digunakan.

Yang Dipelajari

Box Model

Mengatur margin, border, padding, dan ukuran elemen dengan tepat.

Flexbox

Menyusun elemen secara fleksibel dan menjaga layout tetap responsif.

UI Terstruktur

Membuat tampilan portfolio yang konsisten dan mudah dinavigasi.
