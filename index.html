Tentang Saya

Saya memiliki ketertarikan besar pada pengembangan aplikasi web modern, mulai dari merancang antarmuka yang bersih dan responsif di sisi frontend, hingga membangun logika server, database, dan API di sisi backend. Selama masa kuliah, saya aktif mengerjakan berbagai proyek pribadi maupun tim, seperti aplikasi manajemen tugas, sistem kasir sederhana, dan landing page untuk UMKM. Dari pengalaman tersebut, saya belajar banyak tentang problem solving, kerja sama tim, serta pentingnya menulis kode yang rapi dan mudah dipelihara. Saat ini saya terus mengasah kemampuan di ekosistem JavaScript/TypeScript, framework modern, dan praktik DevOps dasar. Saya percaya bahwa belajar tidak pernah berhenti, dan setiap proyek adalah kesempatan untuk berkembang. Jika Anda tertarik untuk berkolaborasi atau ingin melihat karya saya lebih dekat, silakan jelajahi halaman ini atau hubungi saya melalui kontak yang tersedia
